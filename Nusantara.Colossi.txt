Notes:
- Dibangun dengan .NET 10 + Rust (low level library - jika diperlukan) + Avalonia UI + Three.Net (https://github.com/DotNetVibeCoderz/Vibe_Graphics/tree/main/ThreeNet) untuk target multi-platform (windows, mac, Linux dan android)
- Optimasi kode dengan best practice, best performance dan efisiensi memory
- Dokumentasi yang lengkap, jelas, mudah dengan dua Bahasa (English dan Bahasa Indonesia)
- Tambahkan screenshot-nya ke readme dan docs
- Tambahkan info pada dokumentasi dan aplikasi: Dibuat oleh Ariana Mischa Fadhila dari Syubadubin Studios  
- PLAN.md untuk roadmap pengembangan, dan Progress.md untuk tracking development
- UI UX-nya yang keren dan professional dibantu dengan skill 'frontend-design' 
- Untuk sculpting, rigging, animating gunakan Blender MCP
- Untuk generate 3D model dan aset yang kompleks untuk karakter utama, musuh raksasa, dan objek game lain yang butuh detail dan presisi gunakan rodin mcp (Hunyuan 3D)
- Untuk generate Image dan 2D Art bisa dibantu Rodin MCP (Gpt Image Flare)
- Buat dengan grafik sekelas AAA game, dengan VFX, animasi, environment, sound, music yang keren dan epic
- Lengkapi lagi ide game-nya biar lebih seru, tegang dan menyenangkan
